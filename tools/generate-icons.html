Classic Tetris — PWA icon generator

One-off browser tool. Click each Download button, save the files into public/icons/ (replacing the existing placeholders), then run npm run build and commit. The tool draws a stylized T-tetromino with the same NES-style light/dark inset used in-game, on a solid background. The maskable variant leaves a safe zone so Android can crop to various mask shapes without clipping the shape.
